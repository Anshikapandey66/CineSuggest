
# 🎬 CineSuggest — Movie Recommendation App

### Discover your next favorite movie 🍿

CineSuggest is a modern and responsive movie recommendation website that helps users explore movies, search by title, filter by genre, and save their favorite movies to a personal watchlist.

## ✨ Features

- 🔍 **Movie Search** — Search movies by title, genre, or description.
- 🎭 **Genre Filters** — Browse Action, Sci-Fi, Romance, Comedy, Thriller, and Drama.
- ⭐ **Movie Ratings** — View movie ratings and release years.
- 🎲 **Surprise Me** — Get a random movie recommendation.
- ❤️ **Personal Watchlist** — Save or remove movies from your watchlist.
- 💾 **Local Storage** — Your watchlist stays saved in your browser.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile.
- 🌙 **Dark UI** — Enjoy a modern dark-themed interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- TMDB image URLs for movie posters

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/CineSuggest.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start exploring movies!

## 🌐 Deploy on GitHub Pages

1. Open your GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Click **Save**.
6. Wait for deployment to complete.

Your website URL will be:

https://YOUR-USERNAME.github.io/CineSuggest/

Replace `YOUR-USERNAME` with your GitHub username.

## 🎯 Project Objective

The objective of CineSuggest is to create an interactive movie discovery experience using frontend web technologies while practising JavaScript, responsive design, event handling, filtering, and browser storage.

## ⚠️ Disclaimer

This project uses a predefined demo movie dataset. Movie posters load from external image URLs, so an internet connection is required for them to appear. Watchlist data is stored locally in the browser.
